# CodeAlpha_BasicChatbot

Rule-based chatbot for the CodeAlpha Python internship (Task 4).

## What it does
- Reads user input in a loop.
- Replies to `hello`, `how are you`, and `bye` with fixed messages.
- Exits on bye / goodbye / exit / quit.

## How to run
```bash
python chatbot.py
```

## Concepts used
if-elif, functions, loops, input/output.
